O menu Zac

O menu Zac é o Zac sorridente na extremidade esquerda da barra de menus. Ele está lá seja qual for o programa da frente.

  • Sobre este computador… mostra qual versão do ZacOS você tem e como a memória está sendo usada.
  • Novos truques abre o catálogo de programas que você pode instalar. Buscar atualizações verifica se há uma versão mais recente do ZacOS e atualizações do sistema.
  • Forçar encerramento lista os programas abertos; escolha um que parou de responder para encerrá-lo.
  • Old Dog inicia o Mac OS clássico. Veja Old Dog.
  • Captura de tela permite arrastar sobre parte da tela; a imagem vai para a mesa como “Picture 1.png” e para a área de transferência.
  • Instalador do Windows instala um programa do Windows para executá-lo no ZacOS.
  • Vizinhança conecta a outros computadores. Veja Redes.
  • Seletor de impressora escolhe a impressora para a qual vão seus documentos. Veja Imprimir.
  • Painéis de controle lista todos os painéis de controle. Veja Painéis de controle.
  • Aplicativos recentes, Documentos recentes e Servidores recentes listam o que você abriu por último. Quantos cada um guarda é definido no painel Opções do menu Zac.
  • Bloco de notas guarda oito páginas de notas; passe entre elas com Página ▸ Página anterior e Página seguinte.
  • Gravador grava um som em um arquivo WAVE e o reproduz. Use Abrir para reproduzir uma gravação WAVE que você já tenha.
  • Stash guarda imagens e trechos de texto para usar de novo, um por página. Escolha Colar, ou arraste texto, uma imagem ou um arquivo de imagem ou texto, para adicionar uma página depois da que você vê; Copiar, ou arrastar a página para fora, para usá-la em outro lugar. Recortar e Apagar removem a página, e Desfazer a devolve. Folheie as páginas com a barra de rolagem ou as teclas de seta.
  • Teclas mostra qual caractere cada tecla digita com seu layout de teclado. Mantenha Shift ou Alt Gr, ou clique em Shift ou Opção na imagem, para ver os caracteres que eles produzem; as teclas contornadas adicionam um acento à próxima letra que você digitar. Digite, ou clique nas teclas, para montar uma linha que você possa copiar. O menu Layout mostra seus outros layouts.
  • Quebra-cabeça corta uma imagem em peças para você montar de novo. Escolha Quebra-cabeça ▸ Abrir imagem… para usar sua própria imagem, e um tamanho de peça no mesmo menu.
  • Plotter desenha o gráfico de uma equação como sin(x) ou x^2 - 3x. Digite-a e pressione Return; os botões de zoom aproximam ou afastam.
  • Mantenha Shift pressionado ao escolher Iniciar sessão para iniciar em modo de segurança sem os itens de inicialização.
  • Favoritos lista os itens que você adicionou com Arquivo ▸ Adicionar aos Favoritos.

Escolher o que há no menu Zac

Os itens abaixo de Servidores recentes são os que estão em Pasta Sistema ▸ Itens do menu Zac, em ordem alfabética. Ele começa com um alias de cada acessório de mesa (Calculadora, Dog Ears, Quebra-cabeça, Plotter e o resto) e do terminal.

  • Para adicionar algo, coloque um alias dele em Itens do menu Zac: um programa, um documento, uma pasta ou um disco. Pastas dentro de Itens do menu Zac viram submenus, até quatro níveis de profundidade.
  • Para tirar algo por enquanto, arraste-o para Pasta Sistema ▸ Itens do menu Zac (desativados); arraste-o de volta para colocá-lo de novo. Para tirar de vez, arraste-o para o Lixo.
  • Programas e scripts em Itens do menu Zac ▸ Tarefas automatizadas aparecem em seu próprio submenu e são executados ao serem escolhidos.

Os itens que você tira continuam fora: o ZacOS não os coloca de volta.
