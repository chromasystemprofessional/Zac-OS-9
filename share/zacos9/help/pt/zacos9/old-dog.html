Old Dog: executar software clássico para Mac

O Old Dog executa o Mac OS clássico em uma janela, para você usar programas escritos para ele. Ele não vem com o software da Apple: você fornece um arquivo ROM de Macintosh e um disco de sistema, de um Mac que seja seu.

Configurar

  1. Crie uma pasta chamada Classic na sua pasta de início.
  2. Coloque nela um arquivo ROM: uma ROM de Power Mac Old World (de um Power Mac 7200 a 9600) ou o arquivo “Mac OS ROM” de um CD do Mac OS 9. Os nomes dos arquivos não importam; o Old Dog os reconhece.
  3. Coloque nela suas imagens de disco: uma imagem de disco rígido Mac já instalada (.dsk ou .hfv), ou uma imagem de CD de instalação do Mac OS (.iso, .toast ou .cdr).
  4. Escolha menu Zac ▸ Old Dog.

Se você só tem uma imagem de CD, o Old Dog cria ao lado dela um disco rígido vazio de 2 GB para instalar; o instalador do Mac OS oferece inicializá-lo.

De qual disco ele inicia

O Old Dog inicia de um disco rígido com Pasta Sistema antes de um CD. Para escolher, abra Painéis de controle ▸ Disco de inicialização e escolha um disco em “Old Dog inicia com:”. Só são listados discos com uma Pasta Sistema.

Compartilhar arquivos com o Mac

  • Sua pasta de início aparece na mesa do Mac como um disco chamado Unix.
  • Se você ativar o Compartilhamento de arquivos dentro do Mac OS, o ZacOS pode se conectar a ele: na Vizinhança, conecte-se a 127.0.0.1:5548.
  • O Mac chega a este computador em 10.0.2.2.
