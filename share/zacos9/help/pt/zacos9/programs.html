Abrir, alternar e instalar programas

Abrir programas

Clique duas vezes em um programa em Zacintosh HD ▸ Aplicativos, ou em um documento para abri-lo com seu programa. Para manter os programas por perto, use o Toy Box, os Favoritos do menu Zac ou uma tecla de função.

Opção-clique duas vezes em um programa em execução para fechar sua janela da frente sem encerrar o programa.

Se nenhum programa puder abrir um documento, o ZacOS oferece os programas que podem abrir aquele tipo de arquivo; o painel Tradutor de arquivos lembra suas escolhas.

Alternar entre programas

  • O menu Aplicativo, na extremidade direita da barra de menus, lista os programas abertos. Escolha um para trazê-lo para a frente. Ocultar [programa] oculta o da frente, Ocultar outros oculta os demais e Mostrar tudo os mostra de novo. Arraste a alça estriada logo à esquerda dele para a direita para mostrar ali o ícone do programa em vez do nome, e assim ter mais espaço, e para a esquerda para voltar ao nome; um clique também alterna.
  • Mantenha Opção pressionado ao escolher outro programa para ocultar o que você deixa.
  • Pressione ⌘-Tab para ir ao próximo programa, ⇧⌘-Tab para o anterior.
  • Opção-clique na mesa para ir ao Sniffer e ocultar o programa em que você estava. Manter Opção pressionado ao escolher outro programa no menu Aplicativo também oculta o que você deixa.
  • Arraste o menu Aplicativo para baixo, para fora da barra de menus, para destacar o Pack, uma paleta com um bloco para cada programa aberto. Clique em um bloco para alternar; solte um documento em um bloco para abri-lo naquele programa. O quadrado de zoom dele mostra os nomes dos programas.

Teclas de função

Em Teclado ▸ Teclas de função você pode dar a F1 a F12 um programa, documento ou pasta para cada uma. Pressionar a tecla o abre, ou o traz para a frente se já estiver aberto.

Quando um programa para de responder

Escolha menu Zac ▸ Forçar encerramento e o programa. Tudo o que ele não tiver salvado se perde.

Instalar programas

  • menu Zac ▸ Novos truques é um catálogo de programas. Escolha um e clique em Instalar; pode ser que peçam sua senha.
  • menu Zac ▸ Instalador do Windows instala um programa do Windows a partir do instalador (.exe) para executá-lo no ZacOS.
  • Para remover um programa, arraste-o de Aplicativos para o Lixo. Ele é desinstalado quando você esvazia o Lixo; Guardar cancela isso.

Manter-se atualizado

menu Zac ▸ Buscar atualizações verifica se há uma nova versão do ZacOS e atualizações do sistema, e as instala.
