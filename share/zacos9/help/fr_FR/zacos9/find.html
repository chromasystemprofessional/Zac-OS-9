Rechercher des fichiers

Choisissez Fichier ▸ Rechercher… (⌘-F) dans le Sniffer. Tapez une partie d'un nom et cliquez sur Rechercher ; ce qui est trouvé apparaît dans une fenêtre dans laquelle vous pouvez travailler comme dans toute autre.

Plus de choix

Choisissez où chercher (tous les disques, votre dossier personnel ou le dossier au premier plan), puis ajoutez des lignes de critères. Un fichier doit correspondre à chaque ligne pour être trouvé. Les lignes peuvent porter sur :

  • le nom (contient, commence par, se termine par, est, n'est pas, ne contient pas) ;
  • la date de modification ou de création (aujourd'hui, la semaine ou le mois écoulé, avant ou après une date) ;
  • la taille, le type ou l'étiquette ;
  • les commentaires de l'élément (contient, est, n'est pas ou ne contient pas), ou le fait qu'il ait une icône personnalisée ;
  • le fait qu'un élément soit invisible (fichiers masqués par l'hôte, dont le nom commence par un point) ;
  • la version d'une application (d'après le paquet qui la fournit) ;
  • le fait qu'il soit verrouillé, ou qu'un dossier soit vide ou partagé ;
  • le contenu : les mots à l'intérieur des documents.

Rechercher dans les documents

« Le contenu contient » utilise l'index de recherche du système, qui lit vos documents en arrière-plan. Pour faire indexer un dossier immédiatement, sélectionnez-le et choisissez Fichier ▸ Indexer la sélection.

Utilisez Enregistrer la recherche… pour conserver les critères actuels sous un nom. Recherches enregistrées… exécute une recherche enregistrée dans une fenêtre Éléments trouvés séparée, afin de garder plusieurs résultats ouverts à la fois. Enregistrer à nouveau sous le même nom remplace cette recherche.

Fichier ▸ Rechercher les éléments similaires cherche les documents qui utilisent les mêmes mots inhabituels que celui sélectionné.
