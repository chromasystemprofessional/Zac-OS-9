Old Dog: запуск классических программ Mac

Old Dog запускает классическую Mac OS в окне, чтобы можно было пользоваться программами, написанными для нее. Он не включает программное обеспечение Apple: файл ROM Macintosh и системный диск нужно предоставить самостоятельно, взяв их с принадлежащего вам Mac.

Настройка

  1. Создайте в домашней папке папку с именем Classic.
  2. Поместите в нее файл ROM: ROM Power Mac Old World (от Power Mac 7200 до 9600) или файл «Mac OS ROM» с компакт-диска Mac OS 9. Имена файлов не важны; Old Dog распознает их.
  3. Поместите туда образы дисков: образ установленного жесткого диска Mac (.dsk или .hfv) или образ установочного компакт-диска Mac OS (.iso, .toast или .cdr).
  4. Выберите меню Zac ▸ Old Dog.

Если у вас есть только образ компакт-диска, Old Dog создаст рядом пустой жесткий диск на 2 ГБ для установки; установщик Mac OS предложит его инициализировать.

С какого диска выполняется запуск

Old Dog запускается с жесткого диска, содержащего системную папку, раньше, чем с компакт-диска. Чтобы выбрать диск, откройте «Панели управления ▸ Загрузочный диск» и выберите диск в поле «Old Dog запускается с:». В списке только диски с системной папкой.

Общий доступ к файлам с Mac

  • Ваша домашняя папка появляется на рабочем столе Mac как диск с именем Unix.
  • Если включить общий доступ к файлам в Mac OS, ZacOS сможет подключиться: в «Соседстве» подключитесь к 127.0.0.1:5548.
  • Mac обращается к этому компьютеру по адресу 10.0.2.2.
