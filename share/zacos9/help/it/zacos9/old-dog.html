Old Dog: eseguire software classico per Mac

Old Dog esegue il Mac OS classico in una finestra, così puoi usare i programmi scritti per esso. Non include il software di Apple: devi fornire tu un file ROM di Macintosh e un disco di sistema, da un Mac che possiedi.

Configurarlo

  1. Crea una cartella chiamata Classic nella tua cartella Home.
  2. Metti lì un file ROM: una ROM di Power Mac Old World (da un Power Mac 7200 a 9600) oppure il file «Mac OS ROM» di un CD di Mac OS 9. I nomi dei file non contano; Old Dog li riconosce.
  3. Metti lì le tue immagini disco: un'immagine di un disco rigido Mac installato (.dsk o .hfv), oppure l'immagine di un CD di installazione di Mac OS (.iso, .toast o .cdr).
  4. Scegli menu Zac ▸ Old Dog.

Se hai solo un'immagine di CD, Old Dog crea accanto ad essa un disco rigido vuoto da 2 GB su cui installare; l'installer di Mac OS propone di inizializzarlo.

Da quale disco parte

Old Dog parte da un disco rigido con una Cartella Sistema prima che da un CD. Per scegliere, apri Pannelli di controllo ▸ Disco di avvio e scegli un disco in «Old Dog parte da:». Sono elencati solo i dischi con una Cartella Sistema.

Condividere file con il Mac

  • La tua cartella Home appare sulla scrivania del Mac come un disco chiamato Unix.
  • Se attivi la Condivisione file dentro Mac OS, ZacOS può collegarsi: in Vicinato, collegati a 127.0.0.1:5548.
  • Il Mac raggiunge questo computer su 10.0.2.2.
