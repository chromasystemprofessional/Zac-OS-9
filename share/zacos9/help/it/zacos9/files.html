Copiare, spostare e organizzare i file

Spostare e copiare

  • Trascina un'icona in un'altra cartella dello stesso disco per spostarla; su un altro disco per copiarla.
  • Tieni premuto Opzione durante il trascinamento per copiare invece di spostare.
  • File ▸ Duplica (⌘-D) crea una copia accanto all'originale.
  • Tieni un'icona trascinata su una cartella per un momento e la cartella si apre a molla, così puoi lasciarla più in profondità. Premi Spazio per aprirla senza aspettare. Il ritardo si imposta in Modifica ▸ Preferenze.
  • La finestra di una cartella ha la sua icona nella barra del titolo: trascina quella piccola icona per spostare o copiare la cartella stessa.

Alias

Un alias è un piccolo file che apre qualcos'altro. Seleziona un elemento e scegli File ▸ Crea alias (⌘-M), oppure trascinalo con ⌘-Opzione. File ▸ Mostra originale (⌘-R) trova l'elemento che un alias apre.

Preferiti

File ▸ Aggiungi ai preferiti mette un elemento nel sottomenu Preferiti del menu Zac e nei luoghi offerti dalle finestre Apri e Salva.

Ritagli

Trascina testo selezionato, un'immagine o un collegamento da un altro programma sulla scrivania o in una cartella, e diventa un file ritaglio: «…clipping.txt» per il testo, «picture clipping.png» per un'immagine, o una posizione Internet («.url») per un collegamento. Fai doppio clic su un ritaglio per vederlo, trascinalo in un documento per inserirne il contenuto, oppure fai doppio clic su una posizione Internet per aprirla nel browser.

Gli appunti

Taglia (⌘-X), Copia (⌘-C) e Incolla (⌘-V) funzionano tra i programmi. Nello Sniffer, Copia mette i nomi degli elementi selezionati negli appunti come testo; non copia i file. Modifica ▸ Mostra appunti apre una finestra che mostra cosa c'è negli appunti in quel momento.

Cifrare un file

Seleziona un file e scegli File ▸ Cifra… per salvare una copia separata protetta da passphrase. ZacOS usa la cifratura GPG; ti chiede di inserire la passphrase due volte. Il file originale non viene modificato. Seleziona un file cifrato e scegli File ▸ Decifra… per salvare una copia decifrata. Conserva la passphrase al sicuro: l'integrazione opzionale con il portachiavi non è ancora disponibile.

Finestre Apri e Salva

I programmi chiedono dove aprire o salvare i file in una finestra di ZacOS. I tuoi Preferiti sono offerti lì. Comandi generali decide in quale cartella si apre la finestra: quella scelta dal programma, l'ultima usata in quel programma o Documenti. Il pulsante Recenti elenca i documenti e le cartelle usati di recente: scegline uno per andarci. Puoi anche trascinare una cartella dallo Sniffer sulla finestra per aprirla lì.

Cartelle recenti offre anche le dieci cartelle più recenti disponibili sul disco selezionato.

Nell'elenco dei file, digita un nome per selezionarlo; usa i tasti freccia per spostarti tra gli elementi.

Dischi

Seleziona un disco e scegli Speciale ▸ Espelli (⌘-E) prima di scollegarlo. Speciale ▸ Inizializza disco… cancella il disco selezionato e lo formatta di nuovo.
