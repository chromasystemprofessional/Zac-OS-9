Trovare i file

Scegli File ▸ Trova… (⌘-F) nello Sniffer. Digita parte di un nome e fai clic su Trova; i risultati appaiono in una finestra in cui puoi lavorare come in qualsiasi altra.

Più scelte

Scegli dove cercare (tutti i dischi, la tua cartella Home o la cartella in primo piano), poi aggiungi righe di criteri. Un file deve soddisfare ogni riga per essere trovato. Le righe possono considerare:

  • il nome (contiene, inizia con, termina con, è, non è, non contiene);
  • la data di modifica o di creazione (oggi, l'ultima settimana o l'ultimo mese, prima o dopo una data);
  • la dimensione, il tipo o l'etichetta;
  • i commenti dell'elemento (contiene, è, non è o non contiene), oppure se ha un'icona personalizzata;
  • se un elemento è invisibile (file nascosti dal sistema, il cui nome inizia con un punto);
  • la versione di un'applicazione (dal pacchetto che la contiene);
  • se è bloccato, oppure se è una cartella vuota o condivisa;
  • il contenuto: le parole dentro i documenti.

Cercare dentro i documenti

«Il contenuto include» usa l'indice di ricerca del sistema, che legge i documenti in background. Per far leggere subito una cartella, selezionala e scegli File ▸ Indicizza selezione.

Usa Salva ricerca… per conservare i criteri attuali con un nome. Ricerche salvate… esegue una ricerca salvata in una finestra Elementi trovati separata, così puoi tenere aperti più risultati insieme. Salvando di nuovo con lo stesso nome sostituisci quella ricerca.

File ▸ Trova elementi simili cerca i documenti che usano le stesse parole insolite di quello selezionato.
