Keyboard shortcuts

⌘ is the Command key (the Windows key on a PC keyboard); Option is Alt.

⌘-OOpen
⌘-PPrint

⌘-MMake Alias
⌘-RShow Original
⌘-YPut Away
⌘-EEject
⌘-FFind…
⌘-ASelect All
⌘-DeleteMove To Trash
⌘-↑Open the enclosing folder (with Option: and close this one)
⌘-?ZacOS Help
⇧⌘-QLog Out

Programs and windows

⌘-Tab, ⇧⌘-TabNext or previous program
⌘-QQuit the program in front
⌘-X, ⌘-C, ⌘-VCut, Copy, Paste
⌘-ZUndo
⌘-SpaceNext keyboard layout
F1 to F12The programs given to them in Keyboard ▸ Function Keys
⌘-drag a title barMove a window without bringing it forward
Option-click a close or collapse boxAll of that program's windows

Accessibility

⌘-Option-KZoom on or off
⌘-Option-↑, ⌘-Option-↓Zoom in or out
Shift five timesSticky Keys on or off
⌘-Shift-ClearMouse Keys on

Emergencies

Control-Option-BackspaceEnd the session at once and return to the login window. Unsaved work is lost.
