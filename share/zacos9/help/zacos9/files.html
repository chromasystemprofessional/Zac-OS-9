Copying, moving and organising files

Moving and copying

  • Drag an icon to another folder on the same disk to move it; to another disk to copy it.
  • Hold Option while dragging to copy instead of moving.
  • File ▸ Duplicate (⌘-D) makes a copy beside the original.
  • Hold a dragged icon over a folder for a moment and the folder springs open, so you can drop it further in. Press Space to open it without waiting. The delay is set in Edit ▸ Preferences.
  • A folder's window has its icon in the title bar: drag that little icon to move or copy the folder itself.

Aliases

An alias is a small file that opens something else. Select an item and choose File ▸ Make Alias (⌘-M), or ⌘-Option-drag it. File ▸ Show Original (⌘-R) finds the item an alias opens.

Favorites

File ▸ Add To Favorites puts an item in the Zac menu's Favorites submenu, and in the places Open and Save dialogs offer.

Clippings

Drag selected text, a picture or a link out of another program onto the desktop or a folder, and it becomes a clipping file: "…clipping.txt" for text, "picture clipping.png" for a picture, or an Internet location (".url") for a link. Double-click a clipping to see it, drag it into a document to put its contents there, or double-click an Internet location to open it in your browser.

The clipboard

Cut (⌘-X), Copy (⌘-C) and Paste (⌘-V) work between programs. In the Sniffer, Copy puts the selected item names on the clipboard as text; it does not copy the files. Edit ▸ Show Clipboard opens a window that shows what's on the clipboard now.

Encrypting a file

Select one file and choose File ▸ Encrypt… to save a separate, passphrase-protected copy. ZacOS uses GPG encryption; it asks you to enter the passphrase twice. The original file is not changed. Select an encrypted file and choose File ▸ Decrypt… to save a decrypted copy. Keep the passphrase safe: the optional Keychain integration is not available yet.

Open and Save dialogs

Programs ask where to open or save files in a ZacOS dialog. Your Favorites are offered there. General Controls decides which folder the dialog starts in: the one the program chooses, the last one you used in that program, or Documents. The Recent button lists the documents and folders you used lately: choose one to go to it. You can also drag a folder from the Sniffer onto the dialog to open it there.

Recent Folders also offers the ten latest folders available on the selected disk.

In the file list, type a name to select it; use the arrow keys to move through the items.

Disks

Select a disk and choose Special ▸ Eject (⌘-E) before unplugging it. Special ▸ Erase Disk… erases the selected disk and formats it again.
