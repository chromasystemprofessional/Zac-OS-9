The Zac menu

The Zac menu is the Happy Zac at the left end of the menu bar. It's there whichever program is in front.

  • About This Computer… shows which version of ZacOS you have and how memory is being used.
  • New Tricks opens the catalog of programs you can install. Fetch Updates checks for a newer ZacOS and system updates.
  • Force Quit lists the open programs; choose one that has stopped responding to end it.
  • Old Dog starts classic Mac OS. See Old Dog.
  • Screen Snapshot lets you drag across part of the screen; the picture goes on the desktop as "Picture 1.png" and on the clipboard.
  • Windows Installer installs a Windows program to run on ZacOS.
  • Neighbourhood connects to other computers. See Networks.
  • Printer Picker chooses the printer your documents go to. See Printing.
  • Control Panels lists every control panel. See Control panels.
  • Recent Applications, Recent Documents and Recent Servers list what you opened last. How many each keeps is set in the Zac Menu Options control panel.
  • Notepad keeps eight pages of notes; move between them with Page ▸ Previous Page and Next Page.
  • Bark Recorder records a sound to a WAVE file and plays it back. Use Open to play a WAVE recording you already have.
  • Stash keeps pictures and pieces of text to use again, one to a page. Choose Paste, or drag text, a picture or a picture or text file onto it, to add a page after the one you see; Copy, or drag the page out, to use it somewhere else. Cut and Clear remove the page, and Undo puts it back. Leaf through the pages with the scroll bar or the arrow keys.
  • Key Tags shows which character each key types with your keyboard layout. Hold Shift or Alt Gr, or click Shift or Option in the picture, to see the characters they give; outlined keys add an accent to the next letter you type. Type, or click keys, to build a line you can copy. The Layout menu shows your other layouts.
  • Jigsaw Puzzle cuts a picture into pieces for you to put back together. Choose Puzzle ▸ Open Picture… to use your own picture, and a piece size from the same menu.
  • Plotter draws the graph of an equation such as sin(x) or x^2 - 3x. Type it and press Return; the zoom buttons take you closer or further away.
  • Hold Shift while choosing Log In to start in safe mode without Startup Items.
  • Favorites lists the items you added with File ▸ Add To Favorites.

Choosing what's in the Zac menu

The items below Recent Servers are whatever is in System Folder ▸ Zac Menu Items, in alphabetical order. It starts with an alias of each desk accessory (Calculator, Dog Ears, Jigsaw Puzzle, Plotter and the rest) and of the terminal.

  • To add something, put an alias of it in Zac Menu Items: a program, a document, a folder or a disk. Folders inside Zac Menu Items become submenus, up to four levels deep.
  • To take something out for now, drag it to System Folder ▸ Zac Menu Items (Disabled); drag it back to put it in again. To take it out for good, drag it to the Trash.
  • Programs and scripts in Zac Menu Items ▸ Automated Tasks appear in their own submenu and run when chosen.

Items you take out stay out: ZacOS doesn't put them back.
