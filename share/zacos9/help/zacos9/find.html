Finding files and the web

Choose Bloodhound (Search) from the Zac menu, the Applications folder or the desktop. The icons along the top are its channels, as in Sherlock 2: Files, Internet, People, Shopping, News, ZacOS, Reference and My Channel, then any channels you make. The chosen icon is pressed in; Hint Bubbles name each one, and ⌘1 to ⌘8 choose the fixed channels.

In the Files channel, type part of a name, choose where to look, and press Search; what's found appears in the window you can work in like any other. More Choices adds criteria, Saved… brings a query back, Recents… brings back a recent one, and Live Search searches as you type. A result's contextual menu has Find Similar Items, and Preview shows the selected result below the list. The Sniffer's File ▸ Find… (⌘-F) opens the Find window with the same engine.

The other channels

Internet searches with any search site you have, a general engine first. Shopping, News and Reference group sites of their kind; the results open in your browser, and Bloodhound never fetches or shows the page itself. People lists the people who can use this computer, with their full names and Home folders; type part of a name to narrow the list, and open a person's Home folder from it. ZacOS is the Help Center channel: type words and press Search to search ZacOS Help, or press Search with the field empty to open the Help Center. My Channel holds your own sites.

More choices

Choose where to look (all disks, your Home folder, or the folder in front), then add rows of criteria. A file must match every row to be found. Rows can look at:

  • the name (contains, starts with, ends with, is, is not, doesn't contain);
  • the date modified or created (today, the past week or month, before or after a date);
  • the size, kind or label;
  • the item's comments (contains, is, is not, or doesn't contain), or whether it has a custom icon;
  • whether an item is invisible (host-hidden files, whose names begin with a dot).
  • an application's version (from its owning package).
  • whether it is locked, or a folder that is empty or shared;
  • the contents: words inside documents.

Searching inside documents

"Contents include" uses the system's search index, which reads your documents in the background. To have a folder read now, choose Index… ▸ Add Folder to Index… in Bloodhound, or select the folder and choose File ▸ Index Selection in the Sniffer. The same menu reports the index's status, removes a folder, or rebuilds the index. Contents results show a snippet with the matched words highlighted.

Drop a folder on Bloodhound to search it, or drop a search-site file on it to add the site to the channel its Channel= line names (Internet, Shopping, News, Reference or a channel of your own).

Use Save Search… to keep the current criteria under a name. Saved… brings it back into Bloodhound; in the Sniffer it runs the saved query in a separate Items Found window, so you can keep several results open at once. Saving again with the same name replaces that query.

Find Similar Items looks for documents that use the same unusual words as the one selected: in Bloodhound's contextual menu (or ⇧⌘F), and in the Sniffer's File menu.
