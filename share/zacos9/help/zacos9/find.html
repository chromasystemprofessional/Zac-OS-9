Finding files

Choose File ▸ Find… (⌘-F) in the Sniffer. Type part of a name and click Find; what's found appears in a window you can work in like any other.

More choices

Choose where to look (all disks, your Home folder, or the folder in front), then add rows of criteria. A file must match every row to be found. Rows can look at:

  • the name (contains, starts with, ends with, is, is not, doesn't contain);
  • the date modified or created (today, the past week or month, before or after a date);
  • the size, kind or label;
  • the item's comments (contains, is, is not, or doesn't contain), or whether it has a custom icon;
  • whether an item is invisible (host-hidden files, whose names begin with a dot).
  • an application's version (from its owning package).
  • whether it is locked, or a folder that is empty or shared;
  • the contents: words inside documents.

Searching inside documents

"Contents include" uses the system's search index, which reads your documents in the background. To have a folder read now, select it and choose File ▸ Index Selection.

Use Save Search… to keep the current criteria under a name. Saved Searches… runs a saved query in a separate Items Found window, so you can keep several results open at once. Saving again with the same name replaces that query.

File ▸ Find Similar Items looks for documents that use the same unusual words as the one selected.
