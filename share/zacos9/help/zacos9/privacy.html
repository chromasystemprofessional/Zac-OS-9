Privacy

ZacOS 9 does not track you. There is no telemetry, no analytics, no online account and no advertising ID. Nothing is reported to the ZacOS project when you install, start or use it.

That is a project rule, not a setting. The source is open, and a test fails if tracking code or an undocumented network address is added.

What stays on your computer

Your documents, settings, accounts, keychain passwords, recent items, search index, clipboard, themes and screen captures stay on your computer. ZacOS does not upload them or keep a copy.

When ZacOS uses the network

  • Software Update asks GitHub for the newest release, and downloads it only when you choose to update. It sends no information about your computer; GitHub sees the request from your address, as any web request is seen. The daily check can be turned off in Software Update.
  • Software asks GitHub for the ZacOS Extras list and your package sources for programs. Nothing about you is sent.
  • Searching the Web in Bloodhound sends your search words to the search site you choose.
  • Neighbourhood looks for Macs and Windows PCs on your local network. It does not use the Internet.
  • File Sharing, Screen Sharing and Mac disks talk only to the computers you choose.

Programs you install, such as a web browser, have their own privacy policies; ZacOS cannot promise what they do.

No usage counting

There is no usage ping, not even an anonymous one, so the project cannot count installations. The full promise and the list of every address ZacOS contacts is in the file PRIVACY.md in the source code.
