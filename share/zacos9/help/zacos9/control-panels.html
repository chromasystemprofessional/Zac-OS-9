Control panels

Choose Zac menu ▸ Control Panels and one of these. Changes take effect at once; there's no OK button.

  • Accessibility: Sticky Keys, Slow Keys, Mouse Keys and Zoom. See Accessibility.
  • Appearance: the theme, accent and highlight colours, the desktop pattern or picture, and the sound set.
  • Bluetooth: find and pair keyboards, mice, headphones and phones.
  • Collar: show or hide The Collar.
  • Date & Time: the date, time and time zone, setting the clock from the network, and how the menu bar's clock looks.
  • File Sharing: share folders with other computers. See Networks.
  • File Translator: which program opens each kind of document.
  • General Controls: whether the desktop shows behind programs, blinking menus and insertion point, the Toy Box at startup, and which folder Open and Save dialogs start in.
  • Internet: your web browser, mail program and downloads folder.
  • Keyboard: key repeat, keyboard layouts (switch with ⌘-Space or the keyboard menu) and Function Keys.
  • Monitors: resolution and size.
  • Mouse and Trackpad: tracking and double-click speed; on a trackpad, tap to click, dragging and drag lock.
  • Nap Time: when the computer and display sleep.
  • Screen Saver: the screen saver, when it starts, and asking for your password afterwards.
  • Sound: the alert sound, volume and output.
  • Startup Disk: which system the computer starts up with, if it has more than one, and which disk Old Dog starts from. Click Restart to start the chosen one now.
  • TCP/IP: Wi-Fi and wired network settings.
  • Users: the people who use this computer. New User… adds an account with its name, short name and password; Open… changes an account's name, picture or password, whether it can administer the computer and whether it can log in; Delete… removes one, keeping its home folder or not. Changing your own name and picture needs nothing; anything else asks for an administrator's password.
  • Toy Box: opens the Toy Box.
  • Zac Menu Options: how many recent items the Zac menu keeps.
