Opening, switching and installing programs

Opening programs

Double-click a program in Zacintosh HD ▸ Applications, or a document to open it in its program. To keep programs close at hand, use the Toy Box, the Zac menu's Favorites, or a function key.

If no program can open a document, ZacOS offers the programs that can open that kind of file; the File Translator control panel remembers your choices.

Switching between programs

  • The Application menu, at the right end of the menu bar, lists the open programs. Choose one to bring it forward. Hide [program] hides the one in front, Hide Others hides the rest, and Show All shows them again.
  • Press ⌘-Tab to go to the next program, ⇧⌘-Tab for the one before.
  • Option-click the desktop to go to the Sniffer and hide the program you were in. Holding Option while you choose another program in the Application menu hides the one you leave, too.
  • Drag the Application menu down off the menu bar to tear off the Pack, a palette with a tile for each open program. Click a tile to switch; drop a document on a tile to open it in that program. Its zoom box shows the programs' names.

Function keys

In Keyboard ▸ Function Keys you can give F1 to F12 a program, document or folder each. Pressing the key opens it, or brings it forward if it's already open.

When a program stops responding

Choose Zac menu ▸ Force Quit and the program. Anything it hadn't saved is lost.

Installing programs

  • Zac menu ▸ New Tricks is a catalog of programs. Choose one and click Install; you may be asked for your password.
  • Zac menu ▸ Windows Installer installs a Windows program from its installer (.exe) to run on ZacOS.
  • To remove a program, drag it from Applications to the Trash. It's uninstalled when you empty the Trash; Put Away cancels that.

Keeping up to date

Zac menu ▸ Fetch Updates checks for a new version of ZacOS and for system updates, and installs them.
