When something goes wrong

A program stops responding

Choose Zac menu ▸ Force Quit and the program. The rest of ZacOS carries on.

Nothing responds

Press Control-Option-Backspace to end the session and return to the login window, then log in again. Anything not saved is lost. If even that doesn't work, hold the power button down until the computer turns off.

The computer starts up with the wrong system

Open Control Panels ▸ Startup Disk, select the system you want and click Restart. If a system you installed isn't listed, click Look for Other Systems.

Disks and network volumes

  • A disk you plugged in doesn't appear: try another port, then look for it in Pedigree's Devices and Volumes.
  • A network volume stops answering: choose Special ▸ Eject on it, then connect again from Neighbourhood or Recent Servers.

Printing

  • No printer is chosen: open Printer Picker from the Zac menu and click one.
  • Printer Picker says the printing service (CUPS) isn't running: start it with sudo systemctl start cups, then try again.
  • A document stays on hold or fails: its queue says why, such as “Stopped (media needed)”. Put in paper or check the printer, then click Resume.
  • One document in a batch doesn't print: the message names it and the rest still print. The session log (below) has the details.

Finding out about your computer

Pedigree (in the Zac menu, or System Folder ▸ System Information) lists your computer's model, processor, memory, displays, disks, network and devices. Its File ▸ Save Report makes a text file you can send to whoever is helping you.

Reporting a problem

Note what you did and what happened. ZacOS keeps a log of the session in the hidden folder .local/state/zacos9 in your home folder (session.log); include it, and Pedigree's report, with your description.
