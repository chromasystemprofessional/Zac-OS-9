Old Dog: running classic Mac software

Old Dog runs classic Mac OS in a window, so you can use programs written for it. It doesn't come with Apple's software: you supply a Macintosh ROM file and a system disk yourself, from a Mac you own.

Setting it up

  1. Make a folder named Classic in your home folder.
  2. Put a ROM file in it: an Old World Power Mac ROM (from a Power Mac 7200 to 9600) or the "Mac OS ROM" file from a Mac OS 9 CD. File names don't matter; Old Dog recognises them.
  3. Put your disk images in it: an installed Mac hard disk image (.dsk or .hfv), or a Mac OS install CD image (.iso, .toast or .cdr).
  4. Choose Zac menu ▸ Old Dog.

If you only have a CD image, Old Dog makes a blank 2 GB hard disk beside it to install onto; the Mac OS installer offers to initialise it.

Which disk it starts from

Old Dog starts up from a hard disk with a System Folder before a CD. To choose, open Control Panels ▸ Startup Disk and pick a disk in "Old Dog starts up with:". Only disks with a System Folder are listed.

Sharing files with the Mac

  • Your home folder appears on the Mac's desktop as a disk named Unix.
  • If you turn on File Sharing inside Mac OS, ZacOS can connect to it: in Neighbourhood, connect to 127.0.0.1:5548.
  • The Mac reaches this computer at 10.0.2.2.
