Accessibility and Zoom

Open Control Panels ▸ Accessibility to turn these on.

Sticky Keys

Press ⌘, Option, Shift or Control once and it stays down for the next key, so shortcuts don't need several keys at once. Press it twice to lock it down; press it again to let go. The menu bar shows which keys are held. Pressing Shift five times turns Sticky Keys on or off.

Slow Keys

A key counts only after it has been held down for a moment, so brushing a key doesn't type it. The slider sets how long.

Mouse Keys

The numeric keypad moves the pointer: 8, 2, 4 and 6 move up, down, left and right, the corner keys diagonally, and 5 clicks. 0 holds the button down for dragging; the period key lets it go. ⌘-Shift-Clear turns Mouse Keys on (Clear is Num Lock on a PC keyboard); Clear by itself turns it off.

Zoom

Zoom magnifies the screen around the pointer, from 2 to 16 times. ⌘-Option-K turns it on or off; ⌘-Option-↑ and ⌘-Option-↓ magnify more or less.
