Buscar archivos

Elige Archivo ▸ Buscar… (⌘-F) en el Sniffer. Escribe parte de un nombre y haz clic en Buscar; lo encontrado aparece en una ventana en la que puedes trabajar como en cualquier otra.

Más opciones

Elige dónde buscar (todos los discos, tu carpeta de inicio o la carpeta que está delante) y luego añade filas de criterios. Un archivo debe coincidir con todas las filas para ser encontrado. Las filas pueden mirar:

  • el nombre (contiene, empieza por, termina en, es, no es, no contiene);
  • la fecha de modificación o de creación (hoy, la última semana o el último mes, antes o después de una fecha);
  • el tamaño, el tipo o la etiqueta;
  • los comentarios del elemento (contiene, es, no es o no contiene), o si tiene un icono personalizado;
  • si un elemento es invisible (archivos ocultos por el sistema, cuyos nombres empiezan por un punto);
  • la versión de una aplicación (la de su paquete propietario);
  • si está bloqueado, o si es una carpeta vacía o compartida;
  • el contenido: palabras dentro de los documentos.

Buscar dentro de documentos

«El contenido incluye» usa el índice de búsqueda del sistema, que lee tus documentos en segundo plano. Para que una carpeta se lea ahora, selecciónala y elige Archivo ▸ Indexar selección.

Usa Guardar búsqueda… para conservar los criterios actuales con un nombre. Búsquedas guardadas… ejecuta una búsqueda guardada en una ventana aparte de Elementos encontrados, así puedes mantener varios resultados abiertos a la vez. Guardar de nuevo con el mismo nombre sustituye esa búsqueda.

Archivo ▸ Buscar elementos similares busca documentos que usan las mismas palabras poco comunes que el seleccionado.
