Old Dog: ejecutar software clásico para Mac

Old Dog ejecuta Mac OS clásico en una ventana, para que puedas usar programas escritos para él. No incluye el software de Apple: tú aportas un archivo ROM de Macintosh y un disco de sistema, procedentes de un Mac que sea tuyo.

Configurarlo

  1. Crea una carpeta llamada Classic en tu carpeta de inicio.
  2. Pon en ella un archivo ROM: una ROM de Power Mac Old World (de un Power Mac 7200 a 9600) o el archivo «Mac OS ROM» de un CD de Mac OS 9. Los nombres de archivo no importan; Old Dog los reconoce.
  3. Pon en ella tus imágenes de disco: una imagen de disco duro Mac ya instalada (.dsk o .hfv), o una imagen de CD de instalación de Mac OS (.iso, .toast o .cdr).
  4. Elige menú Zac ▸ Old Dog.

Si solo tienes una imagen de CD, Old Dog crea a su lado un disco duro vacío de 2 GB para instalar; el instalador de Mac OS ofrece inicializarlo.

De qué disco arranca

Old Dog arranca desde un disco duro con Carpeta Sistema antes que desde un CD. Para elegirlo, abre Paneles de control ▸ Disco de arranque y escoge un disco en «Old Dog arranca con:». Solo se enumeran los discos con una Carpeta Sistema.

Compartir archivos con el Mac

  • Tu carpeta de inicio aparece en el escritorio del Mac como un disco llamado Unix.
  • Si activas Compartir archivos dentro de Mac OS, ZacOS puede conectarse a él: en Vecindario, conéctate a 127.0.0.1:5548.
  • El Mac llega a este ordenador en 10.0.2.2.
