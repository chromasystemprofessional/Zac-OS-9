Le menu Zac

Le menu Zac est le Happy Zac à l'extrémité gauche de la barre de menus. Il est présent quel que soit le programme au premier plan.

  • À propos de cet ordinateur… indique quelle version de ZacOS vous avez et comment la mémoire est utilisée.
  • Nouveaux trucs ouvre le catalogue de programmes que vous pouvez installer. Rechercher les mises à jour vérifie s'il existe une version plus récente de ZacOS et des mises à jour système.
  • Forcer à quitter répertorie les programmes ouverts ; choisissez celui qui ne répond plus pour le terminer.
  • Old Dog démarre le Mac OS classique. Voir Old Dog.
  • Instantané de l'écran vous permet de faire glisser le pointeur sur une partie de l'écran ; l'image est placée sur le bureau sous le nom « Picture 1.png » et dans le presse-papiers.
  • Installateur Windows installe un programme Windows à exécuter sur ZacOS.
  • Voisinage permet de se connecter à d'autres ordinateurs. Voir Réseaux.
  • Sélecteur d'imprimante choisit l'imprimante vers laquelle vos documents sont envoyés. Voir Imprimer.
  • Panneaux de contrôle répertorie tous les panneaux de contrôle. Voir Panneaux de contrôle.
  • Applications récentes, Documents récents et Serveurs récents répertorient ce que vous avez ouvert en dernier. Leur nombre est défini dans le panneau de contrôle Options du menu Zac.
  • Bloc-notes conserve huit pages de notes ; passez de l'une à l'autre avec Page ▸ Page précédente et Page suivante.
  • Enregistreur de sons enregistre un son dans un fichier WAVE et le lit. Utilisez Ouvrir pour lire un enregistrement WAVE que vous possédez déjà.
  • Stash conserve des images et des morceaux de texte pour les réutiliser, un par page. Choisissez Coller, ou faites glisser du texte, une image ou un fichier image ou texte dessus, pour ajouter une page après celle affichée ; Copier, ou faites glisser la page à l'extérieur, pour l'utiliser ailleurs. Couper et Effacer suppriment la page, et Annuler la rétablit. Feuilletez les pages avec la barre de défilement ou les touches fléchées.
  • Étiquettes de touches indique le caractère que produit chaque touche avec votre disposition de clavier. Maintenez Maj ou Alt Gr, ou cliquez sur Maj ou Option dans l'image, pour voir les caractères qu'elles produisent ; les touches entourées ajoutent un accent à la lettre suivante que vous tapez. Tapez, ou cliquez sur les touches, pour composer une ligne que vous pouvez copier. Le menu Disposition affiche vos autres dispositions.
  • Casse-tête découpe une image en pièces que vous devez reconstituer. Choisissez Casse-tête ▸ Ouvrir une image… pour utiliser votre propre image, et une taille de pièce dans le même menu.
  • Plotter trace le graphique d'une équation telle que sin(x) ou x^2 - 3x. Tapez-la et appuyez sur Entrée ; les boutons de zoom vous rapprochent ou vous éloignent.
  • Maintenez Maj enfoncée en choisissant Se connecter pour démarrer en mode sans échec, sans les éléments de démarrage.
  • Favoris répertorie les éléments que vous avez ajoutés avec Fichier ▸ Ajouter aux favoris.

Choisir le contenu du menu Zac

Les éléments situés sous Serveurs récents sont ceux du dossier Système ▸ Éléments du menu Zac, par ordre alphabétique. Il commence par un alias de chaque accessoire de bureau (Calculatrice, Dog Ears, Casse-tête, Plotter et les autres) et du terminal.

  • Pour ajouter quelque chose, placez un alias dans Éléments du menu Zac : un programme, un document, un dossier ou un disque. Les dossiers placés dans Éléments du menu Zac deviennent des sous-menus, jusqu'à quatre niveaux de profondeur.
  • Pour retirer temporairement un élément, faites-le glisser vers le dossier Système ▸ Éléments du menu Zac (désactivés) ; faites-le glisser à nouveau pour le remettre. Pour le retirer définitivement, faites-le glisser vers la corbeille.
  • Les programmes et scripts placés dans Éléments du menu Zac ▸ Tâches automatisées apparaissent dans leur propre sous-menu et s'exécutent lorsqu'on les choisit.

Les éléments que vous retirez restent retirés : ZacOS ne les remet pas en place.
