Réseaux, partage de fichiers et Bluetooth

Se connecter à Internet

Ouvrez Panneaux de contrôle ▸ TCP/IP. Choisissez le Wi-Fi dans « Se connecter via » et votre réseau dans le menu contextuel Réseau, ou branchez un câble. Le module Réseau du Collar indique si vous êtes connecté et active ou désactive le Wi-Fi.

Si TCP/IP signale qu'une connexion n'a pas accès à Internet, les applications peuvent se bloquer lorsque vous êtes aussi en ligne par un autre moyen (un câble vers quelques ordinateurs locaux, par exemple, tandis que votre téléphone vous fournit Internet). Pour un réseau réservé aux ordinateurs proches, choisissez-le dans « Se connecter via », cliquez sur Options… et activez Réseau local uniquement, pas pour Internet. Votre autre connexion transporte alors le trafic Internet.

Se connecter à d'autres ordinateurs

Menu Zac ▸ Voisinage répertorie les ordinateurs proches qui partagent des fichiers : les Mac (AFP, y compris le partage de fichiers de Mac OS 9) et les ordinateurs Windows ou Linux (SMB). Double-cliquez sur l'un d'eux, indiquez votre nom et votre mot de passe si on vous le demande, puis choisissez les volumes auxquels vous connecter. Ils apparaissent sur le bureau comme des disques.

Les serveurs auxquels vous vous êtes connecté sont répertoriés dans Serveurs récents du menu Zac. Pour vous déconnecter, sélectionnez le volume et choisissez Spécial ▸ Éjecter, ou faites-le glisser vers la corbeille.

Partager vos dossiers

Ouvrez Panneaux de contrôle ▸ Partage de fichiers et cliquez sur Démarrer. D'autres ordinateurs, y compris de vieux Mac, peuvent alors se connecter au vôtre. Choisissez les dossiers à partager et les personnes autorisées à les utiliser avec Fichier ▸ Lire les informations ▸ Partage dans le Sniffer. Le module Partage de fichiers du Collar active et désactive le partage et indique qui est connecté.

Bluetooth

Ouvrez Panneaux de contrôle ▸ Bluetooth, mettez votre appareil en mode d'appairage et choisissez-le lorsqu'il apparaît dans la liste. Le module Bluetooth du Collar active et désactive le Bluetooth.
