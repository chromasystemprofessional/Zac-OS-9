Old Dog : exécuter des logiciels Mac classiques

Old Dog exécute le Mac OS classique dans une fenêtre, pour que vous puissiez utiliser les programmes écrits pour lui. Il ne fournit pas les logiciels d'Apple : vous devez fournir vous-même un fichier ROM Macintosh et un disque système, provenant d'un Mac que vous possédez.

Configuration

  1. Créez un dossier nommé Classic dans votre dossier personnel.
  2. Placez-y un fichier ROM : une ROM Old World Power Mac (d'un Power Mac 7200 à 9600) ou le fichier « Mac OS ROM » d'un CD Mac OS 9. Les noms de fichiers n'ont pas d'importance ; Old Dog les reconnaît.
  3. Placez-y vos images disque : une image de disque dur Mac avec système installé (.dsk ou .hfv), ou une image de CD d'installation Mac OS (.iso, .toast ou .cdr).
  4. Choisissez menu Zac ▸ Old Dog.

Si vous ne disposez que d'une image de CD, Old Dog crée à côté un disque dur vierge de 2 Go pour l'installation ; le programme d'installation de Mac OS propose de l'initialiser.

Disque de démarrage

Old Dog démarre à partir d'un disque dur contenant un dossier Système avant un CD. Pour choisir, ouvrez Panneaux de contrôle ▸ Disque de démarrage et sélectionnez un disque dans « Old Dog démarre avec : ». Seuls les disques contenant un dossier Système sont répertoriés.

Partager des fichiers avec le Mac

  • Votre dossier personnel apparaît sur le bureau du Mac comme un disque nommé Unix.
  • Si vous activez le partage de fichiers dans Mac OS, ZacOS peut s'y connecter : dans Voisinage, connectez-vous à 127.0.0.1:5548.
  • Le Mac joint cet ordinateur à l'adresse 10.0.2.2.
