Copier, déplacer et organiser des fichiers

Déplacer et copier

  • Faites glisser une icône vers un autre dossier du même disque pour la déplacer ; vers un autre disque pour la copier.
  • Maintenez Option pendant le glissement pour copier au lieu de déplacer.
  • Fichier ▸ Dupliquer (⌘-D) crée une copie à côté de l'original.
  • Maintenez une icône glissée sur un dossier un instant et le dossier s'ouvre, pour que vous puissiez la déposer plus loin. Appuyez sur Espace pour l'ouvrir sans attendre. Le délai se règle dans Édition ▸ Préférences.
  • La fenêtre d'un dossier porte son icône dans la barre de titre : faites glisser cette petite icône pour déplacer ou copier le dossier lui-même.

Alias

Un alias est un petit fichier qui ouvre autre chose. Sélectionnez un élément et choisissez Fichier ▸ Créer un alias (⌘-M), ou faites ⌘-Option-glisser l'élément. Fichier ▸ Afficher l'original (⌘-R) retrouve l'élément qu'ouvre un alias.

Favoris

Fichier ▸ Ajouter aux favoris place un élément dans le sous-menu Favoris du menu Zac, ainsi que dans les emplacements proposés par les boîtes de dialogue Ouvrir et Enregistrer.

Extraits

Faites glisser du texte sélectionné, une image ou un lien hors d'un autre programme vers le bureau ou un dossier : il devient un fichier extrait : « …clipping.txt » pour du texte, « picture clipping.png » pour une image, ou un emplacement Internet (« .url ») pour un lien. Double-cliquez sur un extrait pour le voir, faites-le glisser dans un document pour y placer son contenu, ou double-cliquez sur un emplacement Internet pour l'ouvrir dans votre navigateur.

Le presse-papiers

Couper (⌘-X), Copier (⌘-C) et Coller (⌘-V) fonctionnent entre les programmes. Dans le Sniffer, Copier place le nom des éléments sélectionnés dans le presse-papiers sous forme de texte ; il ne copie pas les fichiers. Édition ▸ Afficher le presse-papiers ouvre une fenêtre qui montre son contenu actuel.

Chiffrer un fichier

Sélectionnez un seul fichier et choisissez Fichier ▸ Chiffrer… pour enregistrer une copie séparée protégée par une phrase secrète. ZacOS utilise le chiffrement GPG ; il vous demande de saisir la phrase secrète deux fois. Le fichier original n'est pas modifié. Sélectionnez un fichier chiffré et choisissez Fichier ▸ Déchiffrer… pour enregistrer une copie déchiffrée. Conservez la phrase secrète en lieu sûr : l'intégration facultative au trousseau n'est pas encore disponible.

Boîtes de dialogue Ouvrir et Enregistrer

Les programmes demandent où ouvrir ou enregistrer les fichiers dans une boîte de dialogue ZacOS. Vos favoris y sont proposés. Contrôles généraux détermine le dossier dans lequel la boîte de dialogue s'ouvre : celui choisi par le programme, le dernier utilisé dans ce programme, ou Documents. Le bouton Récents répertorie les documents et dossiers utilisés récemment : choisissez-en un pour vous y rendre. Vous pouvez aussi faire glisser un dossier du Sniffer sur la boîte de dialogue pour l'y ouvrir.

Dossiers récents propose également les dix derniers dossiers disponibles sur le disque sélectionné.

Dans la liste des fichiers, tapez un nom pour le sélectionner ; utilisez les touches fléchées pour parcourir les éléments.

Disques

Sélectionnez un disque et choisissez Spécial ▸ Éjecter (⌘-E) avant de le débrancher. Spécial ▸ Effacer le disque… efface le disque sélectionné et le reformate.
