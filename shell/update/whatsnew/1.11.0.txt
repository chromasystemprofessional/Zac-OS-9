Bloodhound, Sherlock's search dog, now has its own program.

Open it from the Zac menu or the Applications folder. Type part of a name,
choose all disks or your Home folder, and press Search. Results show where
each file is, when it changed, its size and kind. Open, Reveal and Get Info
work on a result, Copy Path puts its path on the clipboard, and a result can
be dragged out of the list. Escape stops a search, ⌘R reveals a result and
⌘I gets its information.

Bloodhound 1.0 searches names. More Choices, contents and saved searches stay
in the Sniffer's File ▸ Find… for now; both use the same search engine.
Criteria, contents and the Internet channels are next.
